# PRD Quality Checklist

Use this checklist before delivering a PRD.

## Clarity
- [ ] Problem statement is concrete and specific.
- [ ] Goals are measurable, not vague.
- [ ] Scope boundaries are explicit.

## Completeness
- [ ] Functional requirements cover main and edge flows.
- [ ] Non-functional requirements cover performance, security, reliability.
- [ ] Rollout plan and rollback plan are present.

## Decision Quality
- [ ] Non-goals prevent scope creep.
- [ ] Tradeoffs are visible in risks/mitigations.
- [ ] Open questions are isolated from confirmed decisions.

## Execution Readiness
- [ ] Acceptance criteria are testable.
- [ ] Success metrics include at least one guardrail metric.
- [ ] Assumptions are explicitly marked.

## Collaboration Readiness
- [ ] Document can be read by product, design, and engineering without extra context.
- [ ] Terminology is consistent across sections.
- [ ] No contradictory requirements remain.
