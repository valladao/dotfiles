# PRD Framing Examples

## Typical Trigger Prompts
- "Escreve um PRD para <feature>"
- "Transforma essa ideia em PRD"
- "Preciso de um documento de requisitos para time de produto e engenharia"
- "Refina este PRD e fecha lacunas"

## Good Goal Examples
- "Reduce first-time setup completion time from 12 min to 6 min within 60 days."
- "Increase weekly active usage of feature X from 18% to 30% by end of Q3."

## Weak vs Strong Requirement
- Weak: "System should be fast."
- Strong: "FR-004: The dashboard must render core widgets in <= 2.5s for p95 requests."

## Acceptance Criteria Example Pattern
- AC-001: Given <context>, when <action>, then <observable result>.
- AC-002: Given <edge case>, when <action>, then <safe behavior>.
